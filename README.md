# Моя галерея: фото, видео, обратная связь

Простая галерея на HTML/CSS/JS с вкладками и формой обратной связи.

## Как запустить

1. Открой `index.html` в браузере (локально).
2. Или посмотри онлайн-версию на GitHub Pages.

## Как добавить свои фото и видео

1. Положи файлы в папку `media`.
2. В файле `script.js` обнови массив `items`.

## Важное про форму обратной связи

Форма использует сервис Formspree для отправки писем. Ссылка на форму хранится в переменной в `index.html`.  
⚠️ Не публикуй свою личную почту и не делись endpoint-ссылкой публично без необходимости.
